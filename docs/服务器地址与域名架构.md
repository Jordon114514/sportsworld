# 运动世界 服务器地址与域名架构（实测抓包）

采集时间：2026-11-06 19:23–19:27
设备：OnePlus PJZ110 / Android 17（root）
方法：设备端 `tcpdump` 抓 DNS + TLS，解析 SNI；配合证书透明度日志（crt.sh）与 DNS 解析

---

## 一、抓包方法（可复现）

```bash
# 1. 设备端抓包（root）
adb shell "tcpdump -i any -s 0 -w /data/local/tmp/cap.pcap udp port 53 or tcp port 443 or tcp port 80 &"

# 2. 触发完整启动链路
adb shell "am force-stop com.zjwh.android_wh_physicalfitness"
adb shell "am start -n com.zjwh.android_wh_physicalfitness/.mvi.splash.SplashActivity"

# 3. 停止并取回
adb shell "pkill -f tcpdump"
adb pull /data/local/tmp/cap.pcap

# 4. 解析：DNS 查询 + TLS ClientHello SNI（无需解密 HTTPS）
```

抓包结果：2.5 MB / 3,016 包，解析出 **21 个 TLS SNI 域名**。

**为什么无需解密就能拿到域名**：TLS 握手时 ClientHello 里的 SNI 字段是**明文**。即使全程 HTTPS，目标域名依然暴露。

## 五、服务器地址推测结论

```
                     ┌─────────────────────────────────┐
    App ──HTTPS──►   │  腾讯云 EdgeOne CDN             │
                     │  218.92.141.107  (上海电信)      │
                     │  58.221.54.26    (南京电信)      │
                     │  114.237.67.202  (南京电信)      │
                     └──────────────┬──────────────────┘
                                    │ 回源（IP 被 CDN 隐藏）
                                    ▼
                     ┌─────────────────────────────────┐
                     │  源站：腾讯云 CVM（上海）        │
                     │  证据：管理后台/测试环境/硬编码IP │
                     │  均为 腾讯云 AS45090 上海         │
                     └─────────────────────────────────┘

   图片  swapp-images.iydsj.com ──► 腾讯云 COS（对象存储，独立）
   源码  sw-gitlab.iydsj.com   ──► 81.69.227.161（直连，未过 CDN）
   测试  test.datacollect      ──► 124.220.105.205（裸 nginx）
   后台  118.89.189.246:80     ──► Apache/CentOS，strawberry 选点系统
```

### 关键推断

1. **生产 API 源站 IP 查不到** —— EdgeOne 回源是内网/隐藏的，DNS 与响应头都不泄露。这是 CDN 的正常防护效果。
2. **但托管云已确定**：`test.datacollect`（124.220.105.205）、`sw-gitlab`（81.69.227.161）、硬编码 IP（118.89.189.246）**全部是腾讯云上海（AS45090）**。源站几乎必然也在腾讯云上海同一 VPC 内。
3. **存在多个环境**：生产（CDN）、预发（`pre.payment` / `pre.datacollect`）、测试（`test.datacollect` / `test.payment`）三套。
4. **防护薄弱点**：
   - `test.datacollect` 裸 nginx 无 CDN，暴露版本号
   - `118.89.189.246:80` 管理后台无认证可访问首页
   - `sw-gitlab` 直连公网，GitLab 实例暴露
